# local-live-ja

Japanese low-latency live voice dialogue PoC for a single Linux workstation.

The vertical path is:

`PipeWire microphone -> CPU VAD -> faster-whisper large-v3-turbo (Japanese) -> swappable LLM -> sentence chunker -> Qwen3-TTS 0.6B CustomVoice (Ono_Anna) -> PipeWire speaker`

This is a PoC. It keeps model weights, generated audio, credentials, and raw logs outside Git. See `docs/results.md` for measured status after running the benches.

## Quick start

```bash
uv sync --extra dev --extra voice
uv run local-live doctor
uv run local-live bench asr
uv run local-live bench tts
uv run local-live bench llm
uv run local-live bench e2e
uv run local-live bench aec
uv run local-live bench live-latency
uv run local-live bench aec-matrix
uv run local-live run --input-wav results/artifacts/user.wav
```

All hardware-dependent commands record unavailable measurements as `null` rather than inventing values. The automatic ASR test is named **synthetic ASR regression** because its input is generated by Qwen3-TTS, not human speech.
